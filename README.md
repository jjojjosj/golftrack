# ⛳ GolfTrack

라운딩 중 **큰 버튼 탭 한 번**으로 매 샷을 기록하는 오프라인 골프 스코어 앱.
안드로이드 폰 홈화면에 설치해 인터넷 없이 사용하고, 모든 기록은 기기 안 **SQLite**에 저장됩니다.

## 특징

- **완전 오프라인 (PWA)** — 셀 신호가 약한 골프장에서도 동작. 홈화면에 앱처럼 설치 가능.
- **한 손 조작** — 방향(왼쪽/똑바로/오른쪽) + 결과(페어웨이·러프·벙커·그린·컵인·OB·워터) 버튼.
  버튼 탭 1회 = 샷 1개, 오조작 대비 **되돌리기** 지원.
- **자동 스코어** — 스코어 = 샷 수 + 벌타. 퍼팅 수는 "그린 온 이후 친 샷"으로 자동 계산(클럽 입력 불필요).
- **18홀 기본** (9홀 지원), 홀별 파 조정.
- **기록 보관** — 지난 라운드 스코어카드/샷 상세 조회, `.sqlite` 파일로 **백업 내보내기·가져오기**.

## 기술 스택

- Vite + React + TypeScript
- [sql.js](https://sql.js.org) (SQLite → WebAssembly), IndexedDB에 스냅샷 영속화
- vite-plugin-pwa (Workbox) — 앱 셸 + WASM 프리캐시로 오프라인 지원

## 개발/실행

```bash
npm install
npm run dev        # 개발 서버 (localhost) — PWA/오프라인도 여기서 확인
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 로컬 미리보기
```

`npm run dev`는 `--host`가 켜져 있어 **같은 WiFi의 폰**에서 `http://<PC-IP>:5173` 으로 접속해 볼 수 있습니다.
단, 서비스워커(오프라인/설치)는 **보안 컨텍스트(HTTPS 또는 localhost)** 에서만 등록됩니다.

## 폰에 설치하기

이 앱은 100% 정적 파일이므로 아무 HTTPS 정적 호스팅에나 올리면 됩니다.

```bash
npm run build
# dist/ 를 Netlify / GitHub Pages / Vercel 등 HTTPS 호스팅에 업로드
```

폰 크롬에서 해당 주소를 열고 **메뉴 → 홈 화면에 추가**하면 앱처럼 실행되고 오프라인에서 동작합니다.
(임시로는 `cloudflared tunnel` 같은 HTTPS 터널로도 테스트 가능합니다.)

## 데이터 모델 (SQLite)

- `rounds` — 라운드(코스명, 날짜, 홀 수, 시작/종료 시각)
- `holes` — 홀별 파
- `shots` — 샷별 결과/방향/벌타/순번

스코어 계산 로직은 `src/score.ts`(순수 함수)에 있으며 DB 왕복까지 포함해 검증되었습니다.

## 백업 주의

기록은 이 기기의 브라우저 저장소에 있습니다. **브라우저 데이터를 지우면 기록도 사라지므로**,
설정 화면에서 주기적으로 `.sqlite` 백업을 내보내는 것을 권장합니다.
